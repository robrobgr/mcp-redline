# Roadmap — mcp-redline

Planned milestones and direction for `mcp-redline`.

---

- **Full Internationalization (i18n):** English as the default documentation and interface language with structured machine-readable reason codes and bilingual support.
- **Independent Clean Holdout Evaluation:** Expand evaluation suites with blind test claims authored by independent reviewers who have not seen the engine source code.
- **Standalone CLI Verification Tool:** Command-line runner for deterministic document verification in automated CI/CD security and compliance pipelines.
- **Expanded Document Ingestion:** Built-in extraction for additional formats (PDF, DOCX, CSV/TSV tables) into verifiable verbatim units while keeping the corpus on disk with no network ports.
- **Extended Client Configurations:** Tested configuration templates and guides for major MCP-compatible developer environments and desktop assistants.
- **Enterprise Corpus Benchmarking:** Latency and memory profiling across large document sets with thousands of contractual clauses and tables.
