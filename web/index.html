          Jak Uruchomić mcp-redline (100% Offline)
        

        
      

      

        
        

          

            1
            Instalacja i weryfikacja czystego środowiska (Clean Clone):
          

          

            Wymaga Node.js 18+. Całość działa bez zewnętrznych API i bez wywołań sieciowych.
          

          

            git clone https://github.com/robertgrabowski/mcp-redline.git
cd mcp-redline
npm install
npm test
npm run eval
          

        


        

          

            2
            Konfiguracja w Claude Desktop (claude_desktop_config.json):
          

          

            
{
  "mcpServers": {
    "redline": {
      "command": "node",
      "args": ["/sciezka/do/mcp-redline/dist/index.js"]
    }
  }
}

          

        


        

          

            3
            Kluczowe reguły bezpieczeństwa CISO:
          

          
    
            
  • Transport wyłącznie stdio: Brak portów sieciowych, brak serwera HTTP/SSE.
    • 
            
  • Zero wycieku danych: 100% korpusu pozostaje na dysku lokalnym maszyny użytkownika.
    • 
            
  • Deterministyczny algorytm weryfikacji: Narzędzie verify nie wywołuje LLM – mechanizm antyhalucynacyjny sam nie może halucynować.
