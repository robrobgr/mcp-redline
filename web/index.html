          How to Run mcp-redline (100% Offline)
        

        
      

      

        
        

          

            1
            1. Clean Clone Installation & Verification:
          

          

            Requires Node.js 18+. Runs completely without external APIs or network calls.
          

          

            git clone https://github.com/robertgrabowski/mcp-redline.git
cd mcp-redline
npm install
npm test
npm run eval
          

        


        

          

            2
            2. Claude Desktop Configuration (claude_desktop_config.json):
          

          

            
{
  "mcpServers": {
    "redline": {
      "command": "node",
      "args": ["/sciezka/do/mcp-redline/dist/index.js"]
    }
  }
}

          

        


        

          

            3
            3. Key CISO Security Principles:
          

          
    
            
  • Stdio transport only: No open network ports, no HTTP/SSE server.
    • 
            
  • Zero data leakage: 100% of corpus remains on the local workstation disk.
    • 
            
  • Deterministic verification algorithm: The verify tool does not call an LLM — an anti-hallucination mechanism cannot itself hallucinate.
    •
